---
title: Reading state
description: Favorites, bookmarks, read later, and visit tracking.
---

Sparkfeed stores reading state with each article in the instance database.

- **Favorite** marks an article as important.
- **Bookmark** keeps an article in a saved collection.
- **Read later** creates a reading queue.
- **Visit count** records how often the article was opened through Sparkfeed.

Reading state belongs to the article row in the current workspace data model. Back up PostgreSQL to protect it.
