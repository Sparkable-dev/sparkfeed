## Collect

- Follow RSS and Atom feeds. If a publisher offers both, [compare the two formats](https://sparkfeed.dev/blog/rss-vs-atom/) before adding a second subscription.
- Detect feed links from a website.
- Turn supported listing pages into watched sources.
- [Import and export RSS subscriptions with OPML](/docs/features/import-export-opml/).

## Read and organize

- Use folders and manual source ordering.
- Track favorites, bookmarks, read-later state, and visits.
- Search saved articles.
- Share feeds and folders through public links.

### Copy an image from an article

Open the article in **Reader**. Hover over an inline image or tab to its controls, then select **Copy image**. Paste it into a document that accepts images.

If the browser blocks clipboard access, select **Download image**. If the image host blocks the request, select **Open original image** to view it on the publisher’s site.

## Collaborate

- Create multiple workspaces.
- Invite owners, admins, and members.
- Keep workspace data separated on the server.

## Connect

- Create workspace-scoped API keys.
- Use the REST API.
- Connect an MCP client over streamable HTTP.

## Ask Spark AI

Spark AI can query workspace tools and save conversation history. The operator supplies the model-provider key. Spark AI remains beta.
