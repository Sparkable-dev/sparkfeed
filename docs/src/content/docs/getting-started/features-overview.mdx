---
title: Features
description: Current Sparkfeed Community Edition capabilities.
---

## Collect

- Follow RSS and Atom.
- Detect feed links from a website.
- Turn supported listing pages into watched sources.
- Import and export OPML.

## Read and organize

- Use folders and manual source ordering.
- Track favorites, bookmarks, read-later state, and visits.
- Search saved articles.
- Share feeds and folders through public links.

## Collaborate

- Create multiple workspaces.
- Invite owners, admins, and members.
- Keep workspace data separated on the server.

## Connect

- Create workspace-scoped API keys.
- Use the REST API.
- Connect an MCP client over streamable HTTP.

## Ask Spark AI

Spark AI can query workspace tools and save conversation history. The operator supplies the model-provider key. Spark AI remains beta.
