Sparkfeed is a self-hosted reader and content-intelligence workspace. It follows RSS and Atom feeds and can watch sites that do not publish a feed.

Community Edition includes workspaces, sharing, Spark AI, REST, API keys, and MCP under `AGPL-3.0-only`.

Outside demo mode, Sparkfeed uses PostgreSQL and Better Auth. The first account becomes the instance owner. Later accounts need an invitation unless the operator enables public registration.

Start with the Community Edition installation guide, then configure email before inviting users. Community deployments support up to 10 registered people. Add an operator-owned AI provider key when you want Spark AI.
