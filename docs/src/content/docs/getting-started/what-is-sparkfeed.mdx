---
title: What is Sparkfeed?
description: Feeds, watched pages, workspaces, sharing, AI, REST, and MCP.
---

Sparkfeed collects content from RSS, Atom, and sites without feeds. It organizes those sources into personal or shared workspaces.

The application includes:

- Feed and watched-page ingestion.
- Folders, reading state, search, and sharing.
- Workspace membership and invitations.
- Spark AI conversations over workspace data.
- REST and MCP access through workspace-scoped API keys.

Production and Community installations use PostgreSQL. Demo mode uses a disposable SQLite file and requires no account.
